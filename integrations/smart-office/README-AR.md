# مكتب بلقيس الذكي v26.2.4

نسخة مطورة من آخر مكتب بلقيس المرتبط بالموقع، مع الاحتفاظ بقالب كشف الحساب/PDF v27.4.22.

## الجديد

- **بحث شامل** من زر العدسة أو Ctrl+K / Cmd+K. يبحث في الأقسام الاثني عشر بالاسم ورقم المستند والفاتورة والجوال، ويدعم الأرقام العربية والإنجليزية والتشكيل. يشمل السجلات الأقدم من حد عرض الجداول، ويفتح السجل بأحدث بياناته للتعديل.
- **جداول أسهل**: فرز تصاعدي أو تنازلي من عنوان العمود، وتصفية حسب الحالة أو كلمة البحث، وعداد للنتائج. زر «تصدير النتائج CSV» يصدر الصفوف الظاهرة فقط بعناوين عربية وحماية من تنفيذ صيغ داخل النصوص.
- **مركز العمل**: وصول إلى البحث، وربط حسابات العملاء والموقع، ولوحة المبيعات الخاصة بطلبات تسعير الموقع. لوحة المبيعات تحتاج حساب الإدارة المصرح له في الموقع.
- **الجوال ولوحة المفاتيح**: زر بحث للشاشات الصغيرة، خلفية للقائمة الجانبية، إغلاق بـEscape، تنقل مضبوط داخل النوافذ، وربط أسماء الحقول بها.
- **عرض مريح أو مكثف** من أسفل القائمة. يحفظ المتصفح اختيار العرض فقط؛ نتائج البحث لا تحفظ في التخزين المحلي.

البحث يعرض أول 30 نتيجة مع العدد الكامل للمطابقات. حدّد القسم أو أضف كلمة لتضييق النتائج. الجداول تحتفظ بحد العرض الأصلي: أحدث 800 سجل في القسم؛ البحث الشامل يقرأ السجلات الأقدم أيضًا.

## التثبيت على المكتب القائم

1. ضع **جميع** ملفات الحزمة في المجلد integrations/smart-office داخل مستودع balqeesfloral-arch/balqees123.
2. انشر المصدر على مشروع Vercel القائم balqees-smart-office، مع Root Directory: integrations/smart-office وFramework Preset: Other وOutput Directory: نقطة (.). اترك Build Command بدون تجاوز مخصص. شاشة الربط داخل portal-ui مبنية وجاهزة.
3. احتفظ بمتغيرات الخادم الموجودة في المشروع:

| المتغير | الغرض |
| --- | --- |
| GOOGLE_CLIENT_ID | دخول Google المعتمد |
| BALQEES_ALLOWED_EMAIL | حساب المكتب المصرح له |
| BALQEES_API_SECRET | توقيع جلسة المكتب |
| GOOGLE_SERVICE_ACCOUNT_JSON | اتصال Google Sheets وDrive |
| BALQEES_SPREADSHEET_ID | جدول المكتب الحالي |
| BALQEES_PORTAL_URL | عنوان مشروع Supabase الخاص بالموقع |
| BALQEES_PORTAL_PUBLISHABLE_KEY | المفتاح العام للتحقق من جلسة المدير |
| BALQEES_PORTAL_SECRET_KEY | مفتاح اتصال الخادم بقاعدة الموقع |
| BALQEES_PORTAL_ORIGINS | أصول HTTPS إضافية مصرح بها عند الحاجة |

هذه أسماء إعدادات، ولا تتضمن الحزمة قيم الأسرار. مفاتيح الخادم تبقى في إعدادات Vercel، دون متغيرات VITE_.

4. بعد النشر، افتح المكتب وسجل الدخول بالحساب المعتمد. تحقق من v26.2.4، وابحث عن سجل معروف، وافتح «حسابات العملاء والموقع» لفحص اتصال الربط.

إذا استخدمت مجلد الحزمة كمصدر مستقل، يكون Root Directory جذر المجلد. تشغيل index.html وحده لا يوفر API الخادم أو اتصال قاعدة البيانات.

## الحسابات والتسعير

المستندات وسداد المستحقات والحوالات والبيانات الأصلية تعتمد على نفس Google Sheets وDrive. شاشة ربط العملاء تستخدم نفس API وصلاحيات Supabase الحالية. لا يتطلب الإصدار تغيير مخطط قاعدة البيانات.

طلبات الموقع وتسعيرها تبقى في لوحة الإدارة الخاصة بالموقع. رابط مركز العمل يفتح تلك اللوحة. دورة واتساب الحالية تفتح رسالة الطلب الجاهزة للمبيعات؛ يضغط العميل إرسال داخل واتساب، ويسجل المبيعات السعر في لوحة الإدارة ليظهر للعميل في الموقع.

## التحقق

شغّل npm test من هذا المجلد؛ الاختبارات لا تحتاج مكتبات إضافية. يغطي الاختبار البحث العربي والأرقام، السجلات القديمة والمحذوفة، حد النتائج، الفرز، التصدير، حماية API، وجلب أسماء العملاء الحالية. اتصال Google في الاختبار محاكاة محلية.

اجتازت النسخة فحوص المتصفح على عرض 1440 و768 و390 و320 بكسل: البحث وفتح السجل، التصفية والفرز والتنزيل، حفظ نموذج عميل تجريبي، فتح كشف الحساب الأصلي، الجوال، وانتهاء الجلسة. راجع docs/QA-REPORT.json.

كود المكتب/PDF الأصلي وأصول الشعار والعلامة المائية والتوقيع والختم مطابقة بالبايت للنسخة الأساس. بقي قالب PDF v27.4.22؛ رقم v26.2.4 هو رقم تطبيق المكتب الجديد.
