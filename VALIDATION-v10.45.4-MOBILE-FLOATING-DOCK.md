# Balqees Floral v10.45.4 — Mobile Floating Dock

- Mobile account navigation now uses a floating Liquid Glass dock at the bottom.
- The dock is mobile-only (`<= 720px`).
- Desktop keeps the full account sidebar.
- Tablet keeps a compact sidebar instead of switching to the bottom dock.
- Mobile dock uses six icon-only actions: Home, Store, Orders, Cart, Favorites, Account.
- Active icon is elevated with emerald/gold treatment.
- Cart badge is preserved.
- Safe-area spacing is supported for modern phones.
